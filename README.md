# ScreenCap

Скриншотилка для macOS в духе [Lightshot](https://app.prntscr.com/) — того самого, что
больше не обновляется. Выделяешь область, рисуешь прямо поверх, копируешь или
сохраняешь. Без облака, без аккаунтов, без «поиска похожих в Google».

Нативное приложение на Swift + AppKit. В простое не потребляет CPU, живёт в строке
меню, весит пару мегабайт. Universal-бинарь: Apple Silicon и Intel.

## Что умеет

**Захват**

| Действие | По умолчанию |
| --- | --- |
| Выделить область | ⌘F2 |
| Повторить последнюю область | ⌘F3 |
| Снять окно под курсором | ⌘F4 |
| Снять весь экран | ⌘F5 |

Экран «замораживается» в момент нажатия — можно спокойно целиться в выпадающее
меню или всплывающую подсказку, они никуда не денутся.

**Инструменты рисования**

Карандаш, маркер-хайлайтер, линия, стрелка, прямоугольник, овал, замазывание,
нумерованные кружки, текст и ластик.

*Замазывание* умеет пикселизацию и размытие, форму области — прямоугольник, овал
или кисть, — и регулировку интенсивности.

*Текст* можно поставить на сплошную подложку, на полупрозрачную, дать ему тень
или оставить как есть; цвет подложки выбирается отдельно.

*Ластик* стирает частично, а не целыми объектами: всё нарисованное живёт в
отдельном растровом слое поверх снимка, и ластик выбивает в нём прозрачность —
как если бы вы стирали резинкой по кальке.

**Цвет** — палитра из 18 цветов, недавно использованные, поле HEX, пипетка по
замороженному снимку и кнопка выхода в системную палитру macOS. Всё в одной
панели, без модальных окон.

**Лупа** показывает пиксели вокруг курсора, координаты и цвет в HEX/RGB. Клавиша
`C` без выделения копирует цвет пикселя в буфер.

**Вывод** — буфер обмена, PNG на диск по шаблону имени, «Сохранить как…», печать.

## Горячие клавиши в оверлее

Инструменты: `V` перемещение, `P` карандаш, `H` маркер, `L` линия, `A` стрелка,
`R` прямоугольник, `O` овал, `B` замазать, `N` нумерация, `T` текст, `E` ластик.

Действия: `⌘C` копировать · `⌘S` сохранить · `⇧⌘S` сохранить как (или ⇧-клик по
кнопке сохранения) · `⌘P` печать · `⌘Z` / `⇧⌘Z` отменить и вернуть · `⌘A` весь
экран · `↩` копировать и закрыть · `Esc` отмена · стрелки — сдвиг выделения на
1 px (с `⇧` — на 10) · `⌘↩` — завершить ввод текста.

Модификаторы при рисовании — комбинируются:

| Клавиша | Что делает |
| --- | --- |
| `⇧` | Квадрат / круг, для линии и стрелки — угол кратно 45° |
| `⌥` | Рисовать от начальной точки как от центра |
| `⌃` | Альтернатива инструмента: фигура с заливкой, другой тип замазывания |

Пока зажат `⌃`, иконка активного инструмента в панели меняется — видно, что
именно нарисуется.

Отмена охватывает не только рисование, но и изменение размера и положения самой
области. Серия нажатий стрелок схлопывается в один шаг отмены.

Все сочетания привязаны к позиции клавиши, а не к символу, поэтому работают на
любой раскладке, включая кириллицу.

## Языки

24 локализации; английский используется как запасной для любых недостающих строк.
Язык переключается в меню строки состояния и применяется сразу, без перезапуска.

## Установка

Скачайте `.dmg` из [релизов](../../releases) и перетащите приложение в
«Программы». Или соберите сами:

```bash
make install
```

При первом снимке macOS попросит разрешение на запись экрана:
**Системные настройки → Конфиденциальность и безопасность → Запись экрана**.
После включения приложение нужно перезапустить.

> Приложение подписано ad-hoc, поэтому при первом открытии скачанного `.dmg`
> Gatekeeper будет ругаться. Правый клик по приложению → «Открыть».

## Сборка

Нужен Xcode 15+ (macOS 14+ как цель сборки).

```bash
make app        # universal .app в dist/
make run        # собрать и запустить
make install    # собрать и положить в /Applications
make dmg        # собрать образ для раздачи
make clean
```

Для подписи своим сертификатом:

```bash
make dmg SIGN_ID="Developer ID Application: Имя (TEAMID)"
```

Makefile сам подхватит локальный сертификат подписи, если он есть в связке
ключей — это избавляет от повторного запроса разрешения на запись экрана после
каждой пересборки (macOS привязывает разрешение к подписи).

Разработка без сборки бандла — строки лежат вне бинарника, поэтому на них нужно
указать путь:

```bash
swift build
SCREENCAP_STRINGS=Resources/l10n .build/debug/ScreenCap
```

Полезные флаги при отладке: `SCREENCAP_DEBUG=1` включает трассировку в stderr,
`--capture area|repeat|window|fullscreen` снимает сразу после запуска,
`--window about|preferences` открывает панель.

Самопроверка (рендеринг аннотаций, экспорт PNG, захват экрана):

```bash
.build/debug/ScreenCap --selftest /tmp/screencap-check
```

## Запуск из скриптов

Если нужное сочетание уже занято другой программой, приложение можно дёрнуть
снаружи — из Shortcuts, Raycast, Automator или терминала:

```bash
open "screencap://area"
```

Команды: `area`, `repeat`, `window`, `fullscreen`, `preferences`, `about`.

## Чего здесь нет

Сетевых функций Lightshot: загрузки в prnt.sc, аккаунтов, шаринга в соцсети,
поиска картинки в Google. Приложение не ходит в сеть вообще — единственные
внешние ссылки открываются вручную из окна About.

«Проверить обновления» просто открывает страницу релизов на GitHub: встроенного
апдейтера нет, потому что его нечем подписывать.

## Про другие платформы

Код специфичен для macOS: оверлей, захват экрана и глобальные сочетания
реализованы через AppKit, ScreenCaptureKit и Carbon. Слой аннотаций
(`Sources/ScreenCap/Annotations`) отделён от платформенного и описывает фигуры
в чистой геометрии, но UI под Windows и Linux пришлось бы писать заново.
